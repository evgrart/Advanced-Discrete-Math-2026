## Как решают нестандартные задачи ([KanKov.pdf](https://github.com/evgrart/Advanced-Discrete-Math-2026/blob/main/literature/KanKov.pdf))

Классная книжка, в которой описаны все основные идеи решения задач (двойной подсчёт, Дирихле и т.д.). Стоит ознакомиться, если совсем плохо идут задачи, в книге достаточное количество показательных задач. Не обращайте внимания, что она для младщих классов.
