# Коэффициенты по сериям

Коэффициент считается отдельно для каждой практики. У разных практик может быть разное количество задач и разные границы коэффициентов.

Для каждой серии в таблице указывается:

- общее количество задач;
- минимальное количество решённых задач, начиная с которого действует коэффициент `0.5`, `0.8`, `1` или `1.25`.

Граница включается в следующий диапазон. Например, если для коэффициента `0.8` указано `8`, то при восьми решённых задачах студент уже получает коэффициент `0.8`. Если студент достиг нескольких границ, применяется наибольший доступный коэффициент.

В решённые входят отметки `+` и `1` только на соответствующей практике. Результаты разных практик для вычисления коэффициента не складываются.
